This project is archived in favor of future Fabric ports for VMinus

**VMinus** is a mod that can edit, remove, and replace items, blocks, entities, and more (vanilla or modded) with simple json files. It can be done entry-driven which is the first of its kind, but also optionally config driven if you do not understand datapacks. VMinus also has the capability within these jsons, to allow for global, tagged, and conditional modification to dynamically edit many features at once.
